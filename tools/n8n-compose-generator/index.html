n8n Docker Compose Generator

Generates a production docker-compose.yml (n8n + PostgreSQL 17 + Caddy for automatic HTTPS), a .env with strong random secrets, and a Caddyfile. Secrets are created in your browser with crypto.getRandomValues and are never sent anywhere.

Save your encryption key now. Copy the N8N_ENCRYPTION_KEY line from .env into your password manager. If you lose it, every saved credential in your backups is unreadable. The key starts and ends with . Clicking Generate again creates new secrets.

Using the files

  1. Point a DNS A record for your domain at the server. Open ports 80 and 443.
  2. Put the three files in one folder, e.g. ~/n8n, and run chmod 600 .env.
  3. Run docker compose up -d, then open https://your-domain and create the owner account.
  4. Set up backups before you build workflows: How to back up n8n properly.
